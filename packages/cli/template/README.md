# __APP_NAME__

Generated by [OpenAdminJS](https://js-senpai.github.io/open-admin-js/).

## Stack

- **API** — Nest.js 11 + Prisma 6 (port 4000)
- **Admin** — Next.js 15 back-office (port 3000)
- **Web** — Next.js 15 public site (port 3001)
- **Database** — PostgreSQL, MySQL, or SQLite (chosen during `openadminjs create`)

## Getting started

```bash
pnpm install
pnpm db:migrate   # required on first run (especially for MySQL/SQLite)
pnpm db:seed
pnpm dev
```

Admin panel → http://localhost:3000  
API + Swagger → http://localhost:4000/api/docs  
Public site → http://localhost:3001

Sign in with the superadmin email and password from the scaffold wizard (stored in `apps/api/.env`).

## Environment

Real secrets live in **`apps/api/.env`** only. A tracked **`.env.example`** at the repo root documents the required keys. Never commit `.env` files.

| Provider | Typical `DATABASE_URL` |
| --- | --- |
| PostgreSQL | `postgresql://USER:PASSWORD@localhost:5432/db?schema=public` |
| MySQL | `mysql://USER:PASSWORD@localhost:3306/db` |
| SQLite | `file:./dev.db` |

On **SQLite**, `Json` columns are stored as `String` in the database; the API transparently JSON-encodes/decodes them at runtime.

| Command | Description |
|---|---|
| `pnpm dev` | Start API + admin in parallel |

| `pnpm db:seed` | Seed database (creates superadmin) |

| `pnpm build` | Build all workspaces |
| `pnpm test` | Run all tests |
